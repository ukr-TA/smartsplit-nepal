# SmartSplit Nepal

## Personal Finance and Group Expense Settlement Platform

SmartSplit Nepal is a web-based application designed to simplify shared expense management among friends, roommates, students, travelling groups, and small teams.

The platform allows users to record shared expenses, automatically calculate balances, generate settlement suggestions, and initiate payments through supported Nepalese digital payment services.

## Problem

Managing shared expenses can become difficult when multiple people pay for different items. Users often need to manually calculate balances and determine who owes whom.

Even after calculating the balance, users may need to switch to a separate payment application to complete the settlement.

SmartSplit Nepal aims to simplify this process through a connected workflow.

## Core Workflow

Record Expense → Split Expense → Calculate Balances → Generate Settlement → Initiate Payment → Verify Payment → Update Settlement
